# 阶段 2 结果：SGA 消融 + 负面 prompt 确认

配置：`configs/phase2.yaml`，`Wan2.1-I2V-14B-480P`，**N=40**，`n_max=N`，49 帧 / 832×480 / 16fps，seed 42。
CFG：swan/boat 用组 (1)(2) 的 (2.5, 4.5)；bear 用组 (3) 的 (4.5, 8.5)（`edits.yaml` 的 `overrides`）。
14 次运行，2 个 sweep 作业，全部 rc=0。单节点 8 卡：11 条 1 小时 19 分（串行约 7 小时）。

## 1. 负面 prompt：中文原版决定性胜出

boat_eagle_dive，唯一变量是负面 prompt 文本（同 seed、同噪声流）：

| 预设 | 空间高频保留 | 低频运动相关 |
|---|---|---|
| `none`（空） | 0.16x | +0.119 |
| **`wan_zh`（Wan2.1 官方 `sample_neg_prompt` 中文原文）** | **0.62x** | **+0.405** |
| `wan_en`（diffusers 模型卡英译） | 0.28x | +0.069 |

**干净归因**：阶段 1 的 boat（N=50 + 空负面）是 0.16x / +0.07，阶段 2 的 `neg_none`
（N=40 + 空负面）是 0.16x / +0.119 —— 几乎相同。所以 **N 从 50 降到 40 对 boat 几乎无影响，
全部改善来自中文负面 prompt**。

⚠️ 英译版比空的还差。两个版本看起来同样"官方"（一个在 Wan2.1 仓库，一个在 HF 模型卡），
但效果差距很大。**必须用中文原版。**

## 2. SGA：低频对齐全面改善，温度方向与论文一致

低频运动相关（corr，SGA 要修的就是这个）：

| | base | τ=0.001 | τ=0.01 | τ=1.0 |
|---|---|---|---|---|
| swan | 0.219 | 0.282 | **0.455** | 0.276 |
| boat | 0.405 | **0.530** | 0.459 | 0.285 |
| bear | −0.000 | 0.406 | **0.602** | 0.007 |
| **均值** | 0.208 | **0.406** | **0.505** | 0.189 |

空间高频保留：

| | base | τ=0.001 | τ=0.01 | τ=1.0 |
|---|---|---|---|---|
| swan | 0.83 | 0.69 | 0.71 | 0.70 |
| boat | 0.62 | 0.79 | 0.75 | 0.61 |
| bear | 0.62 | **0.93** | 0.87 | 0.65 |

**结论**：
- **小 τ（0.001 / 0.01）在三条上全部改善低频对齐**，6/6 超过各自基线。论文 5.1 的主张复现。
- **τ=1.0 没有任何收益**（均值 0.189，甚至略低于基线 0.208），视觉上与基线几乎无法区分。
- 因此温度方向与论文 App.D.1 的描述完全一致：
  *"The higher temperature allows more deviation from the source's coarse features"*。
  τ 就是"贴近源 ↔ 允许偏离"的旋钮。

最直观的是 bear：base 熊立起后溶解成棕色雾团、背景全毁；τ=0.001 熊**全程清晰完整**、
石墙岩石植被都在、且确实转身立起完成编辑；τ=0.01 撑到第 4 帧后部分溶解；
τ=1.0 与 base 几乎一样。图见 `outputs/compare/<item>/<item>_grid.png`。

## 3. 关键发现：论文的两档 τ 是「均匀平均」与「硬选择」两个极端

在代码里加了 SGA 诊断日志（打印 cosine 相似度跨度与**有效分支数** = 1/Σw²，
均匀为 5、硬选择为 1）。9 条 τ=1.0 的记录：

```
sim 跨度 0.08 – 0.76    w_max 0.207 – 0.265    有效分支数 4.74 – 5.00
```

**τ=1.0 下权重几乎完全均匀 —— SGA 退化成朴素的 n_avg=5 平均**，
也就是论文 Fig.2 第四行说会导致模糊的那个做法。这解释了它为何毫无收益。

反推另外两档：观测 sim 跨度约 0.1–0.76，则
- τ=0.01 → logits 相差 10–76 → **纯 argmax**
- τ=0.001 → 相差 100–760 → **更纯的 argmax**

即 **0.001 与 0.01 在数值上做的是同一件事**。它们之间的排序在三条视频上不一致（2:1），
应归为噪声而非真实效应。真正的软硬过渡带在 **τ ≈ 0.03–0.3**，论文没有采样这个区间。

⚠️ 这修正了我最初的理解。最初按"正文 0.01 vs 附录 0.001"去跑，等于在硬选择区里比了两个点，
温度消融实质上没做。补了 τ=1.0 之后才构成论文设计的对比。

## 4. 方法学警告：两个启发式指标都有失效模式

- **空间高频能量**在 swan 上给出反直觉结果：base 0.83x "高于" SGA 的 0.69x，
  但画面里 base 的天鹅已经崩成一团、SGA 的羽毛结构清晰可辨。
  原因：崩坏产物是**高频噪点般的杂纹**，梯度幅值反而高。指标量的是"有多少高频纹理"，
  而非"纹理是否有意义"。
- **时间粗糙度**（二阶/一阶差分比）对模糊型退化不敏感，阶段 1 已记录。
- **低频运动相关**在 bear 上与视觉排序不一致（指标说 τ=0.01 > τ=0.001，视觉相反）。

**三个指标都只能当方向性参考，不能当判据。** 稳健的结论只能取"指标与视觉一致"的部分：
小 τ 明显优于 base 与 τ=1.0。阶段 4 的 Gemini VLM 评测因此不是可选项。

## 5. 对阶段 3 的影响

1. ANC 的判据**不能只看时间维指标**——阶段 1 已证时间粗糙度对模糊不敏感。
   需要准备针对"时间不相干"的专门观察方式（例如逐帧固定区域的高频能量方差）。
2. 完整 DynaEdit 应取小 τ。默认用 **τ=0.001**（论文附录值），τ=1.0 保留为"允许偏离"档。
3. 基线锚点：阶段 3 的对照必须是 `p2_sga_t0.001`（SGA 开、ANC 关），而不是 `p2_base`。
